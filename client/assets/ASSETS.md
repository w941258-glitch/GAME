# 素材來源

- `city_atlas.png`：本專案開發期間使用 OpenAI 圖像生成工具建立；非真人照片。4 欄 × 3 列。首列依序為住所、辦公室、咖啡廳、餐廳；後兩列依序對應 lin、zhou、chen、wu、xu、huang、li、wang。Godot 使用 AtlasTexture 顯示各格，原圖不需分割。
- `audio/city_evening.wav`：專案原創合成音樂，16 秒循環。
- `audio/click.wav`、`success.wav`、`error.wav`：專案原創合成音效。
- 音訊可由 `python scripts/generate_audio.py` 重建；僅使用 Python 標準庫，無第三方取樣素材。

此版本是原型美術，尚無角色動畫、差分表情與正式配音。
